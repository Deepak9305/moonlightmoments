# Automated Blog Generation Setup

This guide will help you set up the automated blog generation workflow using GitHub Actions, Groq API, and NASA API.

## Prerequisites

- GitHub repository (already set up ✓)
- Groq API key
- NASA API key (optional, but recommended)

## Step 1: Get Your API Keys

### Groq API Key
1. Go to [Groq Console](https://console.groq.com)
2. Sign up or log in to your account
3. Create a new API key
4. Copy the API key (save it securely)

**Model Used:** `openai/gpt-oss-120b` (optimized for long-form content)

### NASA API Key
1. Go to [NASA API](https://api.nasa.gov)
2. Sign up for a free API key
3. Check your email for confirmation
4. Copy the API key

## Step 2: Add Secrets to GitHub

1. Go to your repository on GitHub
2. Click **Settings** → **Secrets and variables** → **Actions**
3. Click **New repository secret**
4. Add the following secrets:

| Secret Name | Value |
|---|---|
| `GROQ_API_KEY` | Your Groq API key |
| `NASA_API_KEY` | Your NASA API key |

## Step 3: Trigger the Workflow

### Option A: Without Custom Topic (Random Selection)
1. Go to your repository
2. Click **Actions** tab
3. Select **"Generate Blog Post"** workflow
4. Click **"Run workflow"**
5. Leave the topic field empty
6. Click **"Run workflow"**

### Option B: With Custom Topic
1. Go to your repository
2. Click **Actions** tab
3. Select **"Generate Blog Post"** workflow
4. Click **"Run workflow"**
5. Enter your topic (e.g., "Black Holes", "Exoplanets")
6. Click **"Run workflow"**

## Blog Post Output

Each generated blog post:
- **Word Count:** ~800 words
- **SEO Optimized:** Includes keywords and meta tags
- **Includes Images:** From NASA API (or Unsplash fallback)
- **Auto-Published:** Committed and pushed to `pages/blog-posts/` directory
- **Professional Format:** Complete HTML with styling

## Blog Post Location

Generated blogs are stored in:
```
pages/blog-posts/[timestamp]-[topic-slug].html
```

Example:
```
pages/blog-posts/1682505600000-exoplanet-atmospheres.html
```

## Troubleshooting

### "Groq API Key not found"
- Make sure `GROQ_API_KEY` is added to GitHub Secrets
- Verify the key is correct and not expired

### "NASA API failed"
- The workflow will use a fallback image
- Blog will still be generated successfully

### "Rate limit exceeded"
- Groq API has rate limits
- Wait a few minutes before running again
- NASA API allows 40 requests per hour

## Customization

### Add More Topics
Edit `scripts/generate-blog.js` and add topics to the `SPACE_TOPICS` array.

### Change Word Count
Modify the prompt in the `getGroqResponse()` function to adjust the target word count.

### Modify Blog HTML Template
Edit the `formatBlogContent()` function to change the blog post styling and structure.

## API Costs

- **Groq API:** Free tier available with reasonable rate limits
- **NASA API:** Completely free (no authentication required, but key needed for higher limits)

## Auto-Schedule (Optional)

To automatically generate blogs on a schedule, modify `.github/workflows/generate-blog.yml`:

```yaml
on:
  workflow_dispatch:  # Manual trigger
  schedule:
    - cron: '0 0 * * 0'  # Every Sunday at midnight
```
